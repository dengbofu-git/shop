## 0.3.0 - 2026-10-15

- 新增固定版本 BGE 重排序服务、窗口评分和严格候选映射，支持最多 100 条向量召回

### 当前版本补充说明（2026-10-15）

- 新增 `compose.reranker.yml` 和 `deploy/reranker/`，独立部署本地 `BAAI/bge-reranker-v2-m3`，模型版本固定为 `953dc6f6f85a1b2dbfca4c34a2796e7dde08d41e`，与现有 Ollama Embedding 和 PostgreSQL 向量数据分离。
- 服务提供 `/health` 和 `/rerank`，支持启动下载、缓存和预热；当前镜像使用 CPU PyTorch，仅映射本机端口 18081。
- 每个输入由问题和候选正文成对构造，最大 512 tokens，问题最多 96 tokens；长片段使用重叠窗口并取最高分窗口，超出窗口限制显式失败。
- 增加单次推理准入、截止时间和正文大小限制；客户端校验模型版本、完整候选索引、有限分数及原文子串，异常交由检索层执行降级策略。
- 增加固定版本权重并行下载工具，核对官方 LFS SHA256，保留正常下载前缀；模型和 tokenizer 禁止远程代码并使用 safetensors。
- 部署、资源限制与恢复步骤见 [本地重排序](../../docs/本地重排序.md)。本版本未增加知识片段的多语言译文结构。
