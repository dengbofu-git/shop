# 平台运营 (admin_panel)

## 0.4.1 - 2026-10-18

- 平台销售统计复用订单模块统一付款条件，保持现有金额、流水及权限行为。

## 0.4.0 - 2026-10-18

- 新增需有效平台角色与 data_view 的交易总览接口，统计销售额、订单状态流水、订单量、买家和茶企账号、近30天趋势及订单状态分布。
- 分别处理标准订单、试单退货、预售定金／尾款及取消状态，金额使用 Decimal；失败返回503，不返回虚假零值。
- 统计基于保留订单的当前状态，不替代支付或退款对账；新增隔离数据库聚合与鉴权回归验证。

## 0.3.1 - 2026-10-18

- 账号管理改用 user_manage，Agent 管理要求有效平台角色及 system_config，拒绝供应商越权。

## 0.3.0 - 2026-10-15

- 运营设置增加重排序参数、服务状态与调用统计

### 当前版本补充说明（2026-10-15）

- `agent/settings` 扩展重排序配置读写，校验允许模型、字段类型和数量关系，保留配置版本冲突检查及变更审计。
- 新增 `agent/retrieval-status`，返回重排序服务就绪状态、模型版本和计算设备，不向运营端开放任意服务地址配置。
- `agent/monitoring` 增加重排序调用数、失败率、降级率、平均耗时和 P95；P95 基于所选时间范围内最近最多 10000 次调用。
- `agent/traces/<trace_id>` 返回经过白名单过滤的排序明细。新增接口继续要求有效账号和 `system_config` 权限。
- 旧客户端提交原有 Agent 配置字段时保留已有重排序配置，避免保存模型或监控设置时丢失新配置。
