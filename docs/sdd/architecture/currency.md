## 数据与显示

- 商品price、采购车原价、订单项price、订单合计、经营统计按人民币CNY解释。接口金额字段保留，不将参考显示金额回传作为下单价格。支付代码仍读取服务端订单金额，本次不改变支付状态机或验签。
- 唯一参考配置为tea_saas/currency.json：1 CNY分别显示1 CNY、0.14 USD、0.51 AED、0.52 SAR、0.13 EUR。沿用项目已有人民币显示比例，非实时汇率，不代表外币实际扣款。修改配置后需重启后端。
- tea_saas.currency提供Decimal换算及模板上下文；共享主题通过json_script安全提供配置，currency.js先于业务脚本加载。前端统一使用TeaMoney，默认CNY，切换只重绘显示；采购车与确认页按行参考金额合计。
- 订单和Agent卡片允许切换参考显示，付款页固定人民币基础金额。商家编辑／预览标注CNY，内部变量改为priceCny；未来虚拟商品生成标注CNY及price_cny，已有批次报告和数据库属性不批量改写。

## Agent

- 未注明币种默认CNY，required.currency可留空，不伪造用户说过“人民币”的证据。明确外币保留CNY／USD／AED／SAR／EUR及原金额，继续校验原文证据。
- 单价区间查询以Decimal除以对应显示比例，上限向下取人民币分、下限向上取分，过滤真实SKU基础价。
- 总价工具先换算为人民币分再运行组合算法、茶类覆盖、数量和可购买量校验；商品行及bundle_budget以CNY返回，另带requested_currency／requested_maximum和参考外币合计。
- 总价200未标单位时为最高200元，优先190至200元；200美元按0.14参考比例折为最多1428.57元。这是配置算法说明，不是本轮运行的推荐结果。
- 明确外币恰好金额若不能对应整数人民币分，下限大于上限时返回无匹配。参考金额舍入到两位小数，跨币种单价×数量／行合计可能有显示舍入差，基础CNY金额为核对依据。
- 历史客服响应有明确外币标识时保留原样，不按新基础价再次换算；新回复明确人民币单位。其他原始历史金额没有币种字段，本次只统一当前解释，不进行历史外汇对账。
