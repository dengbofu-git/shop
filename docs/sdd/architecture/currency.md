# 人民币基础金额与参考显示

规格0.2.0，2026-10-23，执行R05。基础币种CNY及共用换算已有实现；新增订单币种快照与历史未知投影尚待技术设计及验证。

## 现行金额规则

商品基础price、订单商品价、订单合计、经营统计及Agent确定性计算使用人民币CNY。当前价格数值沿用用户已确认的现状，不自动重算或批量改价。外币显示不回传为订单价格，不决定渠道实际扣款。

唯一参考比例来自tea_saas/currency.json，经tea_saas.currency和currency.js提供；模板安全注入配置，前端使用TeaMoney，默认CNY。修改配置按运行配置要求重载；该比例不是实时汇率，也不代表外币支付承诺。采购车、确认页和商品卡片切换只重绘参考金额，付款页明确基础币种及服务端金额。

采购车每次进入（含刷新）从CNY开始，旧的buyer_cart_currency缓存不覆盖默认值；本页手动切换仍更新参考显示及缓存供后续结算读取。浏览器存储不可用时也保持人民币默认，不影响当前页面手动参考换算。

## 精度与费用

Decimal／整数分计算。外币单价上限换算向下到人民币分、下限向上；总价先换成人民币分再组合，保留用户原币种和原预算。单价×数量、参考行合计可能有显示舍入差，最终核对以基础金额为准。明确恰好金额不能对应整数分时返回无精确匹配，不擅自超支。

商品小计、运费、税费、应付合计分字段表达；未知运税费不得填0或宣称到手总价。预算模式见[总价推荐](../modules/ai-support/total-budget-recommendation.md)。

## 新订单快照与历史兼容

新订单及订单商品快照必须能明确恢复基础币种CNY；具体新增字段或兼容默认方案须设计评审，不能仅靠浏览器当前选择解释金额。需要持久记录外币参考报价时，同时记录参考币种及比例版本／时间，不能用今天的配置冒充历史报价。

历史记录有明确币种则保留原币种和金额；缺币种记录展示“原记录金额／币种未记录”，不批量推断为USD或CNY、不自动换算，不进入跨币种财务比较。历史订单未知币种的支付、退款或正式对账须人工核对，禁止仅靠界面参考换算决定扣款或退款。

本轮不修改业务数据或Migration。原USD默认、缺币种一律追问和不同页面各自比例已退出现行规则，被完整替换的旧正文直接删除。真实支付／退款渠道币种、商户配置和沙箱联调仍须单独确认。
