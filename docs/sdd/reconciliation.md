## 各类SDD材料如何解释

| 材料 | 对账后的效力 |
| --- | --- |
| catalog／feature-inventory | 24个能力映射28项主要功能；另有实现观察字段，不改变candidate／SPEC_REVIEW阶段 |
| current-state／architecture | 表述当前代码实际路径及已知缺口；业务所有权建议不能当成已执行的数据过滤 |
| requirements／acceptance | 保留dengbofu已确认的业务目标；增加当前差异和追踪，不为迁就代码删除404或隐私要求 |
| api-observed | 当前源码和隔离探针观察；当前HTTP错误没有error_code，历史／重放直接返回旧内容 |
| api-contract／design | 待评审目标，包括404短路、新错误码、模板空结果、兼容与回滚；未自动变成现状 |
| redaction／screen-spec | 同时提供当前与目标矩阵；临时ctx引用、读取投影、新历史提示、16状态完整处理仍属目标 |
| test-plan | 更新为当前7组实际回归模块，正式TEST分组仍是计划；101项回归不代表11条AC全量验收 |
| governance／roadmap | 手工渐进准入仍符合当前工具情况；不提升模块MAPPED或能力BUILD_READY |
| 历史evidence | 保留原始64项等历史运行，不覆盖、不与本次101项快照混算 |
