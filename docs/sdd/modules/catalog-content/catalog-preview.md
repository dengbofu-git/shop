# 首页发现与商品采购

更新：2026-10-21，web0.24.3、goods0.5.1。用户确认将首页与商品采购区分职责，并精简采购筛选、恢复属性名；涉及CAP-CAT-001、CAP-PLAT-002。本规格取代此前首页全量分类切换与分页设计，历史证据不再代表当前首页行为。

## 首页规则

- RULE-PREVIEW-001：保留沉浸式商品轮播，不添加左右切换、播放／暂停或查看商品按钮；图片与商品内容沿用整项详情跳转。页脚不添加导航或客服重复入口，不恢复已删除的优势、服务、产地、最近订单及“查看全部”。
- RULE-PREVIEW-002：茶类来自 `GET /v1/goods/index` 的真实分组。每类以商品图片与名称形成原生链接，进入 `buyer_products.html?catalog_id=<ID>`；首页不再本地筛选或显示“全部”标签、SKU总量及分页器。未知茶类按原名展示，常见名称支持中英阿切换。
- RULE-PREVIEW-003：首页精选按分类顺序轮流取一件，分类内按SKU ID降序，去重后固定最多10件。桌面5列2行，不足10件不补虚假商品；不宣称销量排序、人工精选或个性化推荐。语言切换保持同一组SKU。
- RULE-PREVIEW-004：图片及商品名进入详情，采购及收藏沿用现有操作，不恢复预览、溯源或固定GI认证标签。首页失败显示错误及重试，空目录显示空态，加载使用aria-busy。

## 商品采购规则

- RULE-PREVIEW-005：完整目录由采购页承载，默认“全部产品”，保留所有有可售SKU的茶类与数量。默认茶类均衡、单分类SKU ID降序；每页10件，页数按筛选结果计算，末页显示余数。完整目录可遍历全部SKU，无遗漏和重复。页码含首末页、当前页邻近页、省略号及禁用越界按钮，键盘翻页后聚焦当前页。
- RULE-PREVIEW-006：支持商品名／规格／说明／店铺名关键词、价格上下限及店铺名称组合筛选；店铺使用搜索框，按公开店铺名称进行不区分大小写的包含匹配，未匹配时展示空结果。不提供库存筛选，URL中的旧 `min_stock` 不作为查询条件。支持参考价格升降序。价格区间包含边界，以当前展示币种、与卡片一致的两位小数价格判断。重置回全部分类及默认排序，保留币种；切换币种清空旧价格区间并回第一页，避免跨币种误用数值。改变分类或应用条件回第一页，语言切换保留条件与页码。
- RULE-PREVIEW-007：卡片以SPU商品名为标题，SKU名称及说明作规格补充，显示参考价格与已有店铺摘要，不显示库存件数，保留采购及收藏。移除固定阶梯折扣横幅和底部重复推荐区，不新增优惠规则。
- RULE-PREVIEW-008：URL保存 `catalog_id`、`q`、`min_price`、`max_price`、`store_q`、`sort`、`currency`、`page`。首次加载恢复条件；非法分类回退全部，旧 `merchant_id` 下拉条件不再保留，越界页码收敛到有效页。筛选和分页建立浏览器历史，前进／后退重绘对应结果；离开详情前在当前历史项保存滚动位置，异步结果渲染后恢复。顶部商品搜索在采购页内过滤，在其他买家工作台页面进入采购页关键词结果，避免跳至旧商品列表。
- RULE-PREVIEW-009：筛选区显示商品关键词、最低价格、最高价格、店铺名称和排序属性标签，保留三语占位提示和无障碍名称；价格标签与提示包含当前展示币种，输入后仍可辨认字段含义。初始加载禁用筛选表单，失败保留错误及重试；筛选无结果显示独立空态，单页或空结果不显示分页。全部文案支持中英阿语言，窄屏表单与卡片自适应。两页桌面5列，窄屏沿用4／3／2／1列断点。

## 数据与范围

继续使用index一次返回的完整分组，在前端筛选和分页，未新增服务端分页接口。大规模目录优化另行评估。当前接口只返回上架且SKU.stock大于0的SKU和有对应商品的茶类；无库存／下架商品不会出现在目录，因此不增加无效的“缺货”筛选。

公开投影中的 `stock` 继续保留兼容，采购页面不展示数量、不据其提供用户库存条件；此次界面调整不代表新增服务端库存访问权限控制，也不将目录准入改为库存账本口径，不修改库存扣减或订单语义。展示换算沿用工作台现有CNY基值与固定参考比例（USD0.14、AED0.51、SAR0.52）；筛选、排序、卡片使用一致基值，不代表实时汇率或结算金额。店铺筛选使用既有公开摘要，不读取私人账号字段。

实现入口：`buyer-catalog-model.js`共用数据与URL规则；`buyer-catalog-preview.js`负责首页导览与最多10件精选；`buyer-products.js`负责完整目录和采购交互。保留现有详情、收藏、采购车及订单接口，无Migration、数据写入或外部模型调用。
