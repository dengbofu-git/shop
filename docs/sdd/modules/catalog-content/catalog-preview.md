# 首页茶类分类预览

日期：2026-10-18；按用户要求移除四个采购场景按钮，实装茶类预览，并增加每页10件、桌面5列2行的分页浏览。涉及CAP-CAT-001、CAP-PLAT-002，当前web0.11.0。沿用现有商品API及数据，不新增后端接口、Migration或商品数据。

## 规则

- RULE-PREVIEW-001：移除大宗批发、家庭日常、便携年轻、高端礼盒按钮及其虚拟场景过滤。茶类来自 `GET /v1/goods/index` 的 `catalog_id`、`catalog_name`、`sku`；不再硬编码分类名单，也不将所有卡片标记为all。
- RULE-PREVIEW-002：标签显示真实分类名称及可售SKU数量。按分类ID切换，只显示该分类API返回的SKU，不做名称包含匹配。未知的新茶类按原名显示；常见茶类支持中英阿名称，切换语言保留当前选择。
- RULE-PREVIEW-003：每页10件，页数按所选范围的商品总量除以10向上取整，末页显示实际余数。分类内按SKU ID降序；全部分类按API分类顺序轮流取一件，保留完整结果后分页，不再截断到12件。翻页必须能遍历全部SKU，无遗漏、无重复；不将此顺序宣称为销量或智能推荐排序。
- RULE-PREVIEW-004：“查看全部”在全部标签下进入 `buyer_products.html`，在单分类下携带对应 `catalog_id`；此页仍承接完整分类分页。图片、详情、采购及收藏沿用已有卡片行为，溯源继续禁用。
- RULE-PREVIEW-005：加载中设置aria-busy；成功空列表显示空态，失败显示错误和重试，不能以别的茶类填补当前分类。分类按钮使用原生button、aria-pressed及aria-controls，保留键盘操作。
- RULE-PREVIEW-006：分页器包含上一页、下一页及页码，提供首末页直达，长页码范围以省略号收敛；当前页使用aria-current，首末页禁用对应越界按钮。切换分类回到第一页，切换语言保留分类和页码。空态、加载和失败时隐藏分页器。计数显示当前起止范围及总量，翻页后返回商品区域。
- RULE-PREVIEW-007：视口宽度1200px及以上时，满页固定5列2行，卡片等高；不足10件不生成虚假占位商品。窄屏依次调整为4列（992—1199px）、3列（768—991px）、2列（601—767px）、1列（600px及以下）。布局只作用于首页精选区，采购列表布局不变。

## 数据边界

### 2026-10-18 采购列表布局补充

`buyer_products.html` 同步采用桌面5列、每页10件的布局，满页分为上下各5件；末页按实际数量显示，窄屏沿用4／3／2／1列断点。此补充取代前文“采购列表布局不变”的历史范围描述。分类接口新增可选 `page_size`（1至100），采购列表传10；未指定或非法参数仍按原默认12件分页。商品筛选与SKU ID降序不变，禁止先取12件再截掉两件导致跨页遗漏。验证：`goods.test_catalog_pagination`、`client/tests/buyer-products-pagination.test.js`。

后续修正（web0.12.2）：采购页改用 `GET /v1/goods/index` 已返回的全部分类SKU，在客户端固定10件分页，不再依赖分类接口页长。默认选择“全部产品”，各茶类轮流取件形成稳定完整序列；单分类按SKU ID降序。显示分类数量、当前起止范围和总量，分类深链接继续有效，切换分类回第一页，切换语言保留分类与页码。空列表不显示分页器；验证103件跨11页无遗漏、无重复，末页3件。原分类接口的page_size能力保留给既有调用者。

当前index接口仅返回有上架且SKU.stock>0商品的分类，库存判断没有在本次改为账本口径；无可售SKU的数据库分类不会生成标签。预览与采购列表使用同一既有接口口径，不把普洱／花茶等旧静态按钮直接映射到不相关分类。后续数据库新增可售茶类，刷新页面后自动出现。接口一次返回所有分组SKU，前端按10件分页，可遍历全部商品；大规模目录的服务端分页不在本次范围。

实现入口：`client/static/js/buyer-catalog-preview.js`，由首页加载并调用原卡片渲染；`buyer-workbench.js` 保留轮播及公共操作，删除旧场景／茶类假过滤。模板清理旧按钮和示例提示，提供加载、计数、空态、错误、重试区域。

## 验证

`node client/tests/buyer-catalog-preview.test.js` 覆盖每页10件、103件商品共11页且末页3件、跨页无遗漏和重复、分类切换重置、语言切换保留页码、首末页边界、页码直达、空态和失败重试；支持传入Django真实视图在隔离SQLite中返回的JSON，逐分类及全部分类遍历SKU并验证身份。

分页验证见[本次证据](../../evidence/2026-10-18-catalog-pagination/verification.md)，12件预览的[历史证据](../../evidence/2026-10-18-catalog-preview/verification.md)保留。此前浏览器访问被工具的URL策略拒绝，本轮未绕过限制；模板、隔离接口和Node验证不替代浏览器视觉／全链路验收。未访问或修改业务数据库，未提交、推送或部署。
