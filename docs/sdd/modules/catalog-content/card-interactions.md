# 买家商品卡片操作分层

规格0.2.0，2026-10-23。归属CAP-CAT-001／004、CAP-PLAT-002；本文件合并已确认界面规则，删除被替换的预览／溯源旧验收正文，不改变后端。

- RULE-CARD-001：图片与商品名使用明确详情链接；其余空白及说明不绑定采购或导航。
- RULE-CARD-002：价格下方固定主操作行，显示加入采购车及独立收藏／已收藏；收藏复用当前SKU状态、处理中禁用及错误重试，点击不触发采购或详情。
- RULE-CARD-003：首页精选及商品采购卡片不提供快速预览、溯源入口或次操作行，不保留空白分隔。主操作行和详情链接保留，手机无hover也能操作。
- RULE-CARD-004：仅采购按钮调用采购车，登录走现有API，匿名走本地采购车；共用[人民币金额](../../architecture/currency.md)，不改库存和支付事实。
- RULE-CARD-005：完整信息通过图片／商品名进详情；无预览弹层入口。现有推荐小卡片维持独立详情和收藏，不在此重排。
- RULE-CARD-006：不展示溯源占位或固定GI徽标，不用前端标签声称地理标志认证；不恢复已删除的演示页及资源。
- RULE-CARD-007：操作触控高度至少44px，可见键盘焦点，窄屏可换行且不覆盖，保留中英阿和RTL。

## 实现及验收边界

首页与采购列表分别由buyer-workbench.js、buyer-products.js装配，收藏共用buyer-favorites.js；按钮不重复委托。验收包括桌面／375px、空白点击无动作、图片标题进详情、两主按钮互不触发、无次入口／空行、三语及RTL。

既有[验证记录](../../evidence/2026-10-18-card-actions/verification.md)只对应其日期源码与截图；旧预览测试不代表当前行为，不能作为全套现行验收已通过。当前发现与采购布局另见[目录规格](catalog-preview.md)。
