# 买家首页商品轮播

更新：2026-10-19；实现模块web0.18.0；涉及CAP-CAT-001、CAP-PLAT-002。按用户要求改善图片、布局与轮播交互，不扩大商品、价格、库存或交易规则。

## 数据与展示

- 继续读取 `GET /v1/goods/carousel?stable=1&limit=6`。保留现有后端筛选与选择范围；页面不把候选结果称为个性化推荐、销量排名或折扣商品。
- 商品名使用接口title，简介使用intro；全部通过textContent构造。合法SKU去重后最多6件，详情地址由SKU ID生成，不执行响应中的任意链接。
- 图片使用独立img元素，不再作为会被全站主题清掉的背景图。图片失效回退现有占位图，再次失败显示文字，不循环重试。
- 桌面图文分栏，参考价格与“查看商品”独立排列。窄屏800px以下图片移到文字上方，控件和按钮可换行，触控目标至少44px。
- 轮播价格跟随首页已有币种选择和参考换算，与首页卡片复用同一格式化函数；本次不改变首页现有CNY展示基准，也不把它定义成数据库或支付币种事实。相关全站币种问题继续保留。

## 交互规则

- 多件时每6秒自动切换一项，提供前后按钮、可直接选择的圆点、当前计数和暂停／播放。
- 手动切换后保持暂停，用户可主动恢复；鼠标悬停、键盘焦点位于区域、文档不可见或页面挂起时临时停止计时。恢复可播放状态只创建一个计时器。
- 尊重prefers-reduced-motion：默认不自动播放。单件隐藏切换控件且不计时；零件隐藏视口、计数和控件。
- 支持左右方向键及触屏横滑，阿语RTL对应调整方向。纵向滚动不作为切换，横滑后的合成点击不触发详情跳转。
- 隐藏项使用hidden退出可见和键盘操作范围。手动切换通过live region提示，自动播放不反复播报；图像替代文字、按钮、选择器名称和状态提供中英阿三语。
- 加载、空列表与失败分别展示；只有失败显示重试。重复加载忽略过期响应，移除旧幻灯片监听器；销毁时清理计时器和事件，不影响精选商品分页。

## 代码与验证

`buyer-carousel.js`负责轮播状态与控件，`buyer-carousel.css`仅作用于首页轮播；`buyer-workbench.js`装配已有接口、语言和价格函数。无新后端接口、Migration、持久化偏好或业务数据写入。

验证入口：`node client/tests/buyer-carousel.test.js`；`python client/tests/carousel-contract.py <临时JSON路径>`后可将该路径传给Node测试验证真实接口结构。隔离SQLite验证不连接业务库。
