# 买家首页商品轮播

更新：2026-10-20；实现模块web0.21.0；涉及CAP-CAT-001、CAP-PLAT-002。按用户要求增强茶图视觉与动态表现，并移除可见按钮。商品、价格、库存和交易规则不变。

## 数据与展示

- 继续读取 `GET /v1/goods/carousel?stable=1&limit=6`。保留现有后端筛选与选择范围；页面不把候选结果称为个性化推荐、销量排名或折扣商品。
- 商品名使用接口title，简介使用intro；全部通过textContent构造。合法SKU去重后最多6件，详情地址由SKU ID生成，不执行响应中的任意链接。
- 图片使用独立img元素，不再作为会被全站主题清掉的背景图。图片失效回退现有占位图，再次失败显示文字，不循环重试。
- 桌面采用大幅茶图与左侧文案渐变融合，强化商品名、简介和参考价格的层次；整幅作为唯一商品链接，没有“查看商品”按钮和嵌套链接。800px以下调整为上图下文，保留底部非交互细线进度及当前计数。
- 切换时文字柔和入场、图片淡入并在展示期间轻微推近。预取当前及下一幅图片；动画仅作用于透明度和位移／缩放，不给整页添加持续重排。
- 轮播价格跟随首页已有币种选择和参考换算，与首页卡片复用同一格式化函数；本次不改变首页现有CNY展示基准，也不把它定义成数据库或支付币种事实。相关全站币种问题继续保留。

## 交互规则

- 多件时每6秒自动切换一项，只有非交互进度条和当前计数；不显示左右箭头、圆点、播放／暂停及商品操作按钮，无需启动操作。
- 手动切换后重新计时；鼠标悬停、键盘焦点位于区域、文档不可见或页面挂起时临时停止计时和图像推近。离开悬停／焦点后自动恢复，恢复可播放状态只创建一个计时器；进度条与实际计时同步重置。
- 尊重prefers-reduced-motion：默认不自动播放。单件隐藏切换控件且不计时；零件隐藏视口、计数和控件。
- 支持左右方向键及触屏横滑，阿语RTL对应调整方向。纵向滚动不作为切换，横滑后的合成点击不触发详情跳转。
- 隐藏项使用hidden退出可见和键盘操作范围。手动切换通过live region提示，自动播放不反复播报；图像替代文字、操作说明与状态提供中英阿三语。进度条仅作装饰，不增加焦点。
- 加载、空列表与失败分别展示；只有失败显示“重新加载”文字链接，不出现按钮。重复加载忽略过期响应，移除旧幻灯片监听器；销毁时清理计时器和事件，不影响精选商品分页。
