# 买家商品／商家收藏与浏览足迹 v0.2.1

来源：2026-10-16 用户要求补全截图中的“我的收藏”“最近浏览”并更新 SDD。本次请求授权实施；以下默认规则随实现公开，未宣称另行获得业务评审或生产发布批准。

原缺口：`myCollect.html` 重定向回工作台；最近浏览为 `href="#"`；无收藏、足迹存储和 API。

- REQ-CAT-004-01：通过顶部入口进入独立收藏、最近浏览页；页面内部不再重复放置两页切换栏，保留返回商品采购及查看有效商品详情。
- REQ-CAT-004-02：采购列表、工作台精选和推荐商品卡片直接提供收藏／取消入口，同一SKU的按钮状态同步，点击不触发整卡加入采购车或跳转。详情和足迹页保留收藏／取消，刷新后状态持久保存；未登录点击引导登录。
- REQ-CAT-004-03：登录买家成功查看已上架 SKU 详情后记录足迹。同一 SKU 重访只更新查看时间并置顶，最多保留最近 100 件。未登录、详情加载失败不写足迹。
- REQ-CAT-004-04：收藏按收藏时间、足迹按最近查看时间倒序，每页 12 件；可删除单件足迹，确认后可清空足迹，收藏不受清空影响。
- REQ-CAT-004-05：提供加载、空列表、网络失败／重试、登录失效、角色拒绝、操作失败与操作中禁用状态；中、英、阿三语随现有语言切换，阿语采用页面 RTL。
- REQ-CAT-004-06：我的收藏分为“收藏商品”“收藏商家”，分别分页和计数；商品提供详情入口，商家提供店铺入口。店铺主页提供显式收藏／取消商家，刷新或切换设备后从本人记录恢复。分类切换使用 `type=merchants` URL，可返回上一分类；异步旧响应不得覆盖当前分类。

规则：

- RULE-CAT-004-01：仅已激活的 customer 用户可调用私有接口。身份仅取 JWT 用户 ID；请求体／查询串中的用户身份不参与查询，所有读写均过滤当前用户。
- RULE-CAT-004-02：商品收藏与足迹以 `(user, sku)` 唯一，商家收藏独立以 `(user, merchant)` 唯一。重复收藏不新增、不重排；删除幂等。足迹按账号串行写入，确保并发录入时仍受 100 件限制。
- RULE-CAT-004-03：新收藏、足迹写入要求 SKU 存在且已上架；缺货不阻止收藏和足迹。已下架商品保留原记录并标记不可用，支持移除，列表不提供查看按钮。SKU 实体删除时级联删除记录。
- RULE-CAT-004-04：名称、规格、价格读当前商品数据，不保存历史成交价；基础价格为CNY；参考显示按[人民币规格](../../../../architecture/currency.md)，历史币种未知不推断。收藏／足迹不参与计价、库存变动、AI 偏好或匿名历史合并。
- RULE-CAT-004-05：时间为服务器时间，API 使用带时区 ISO 8601；浏览器按所选语言显示。删除最后一页最后一项时页码回落到剩余末页；非法页码返回 400，超出末页回落末页。

- RULE-CAT-004-06：新增商家收藏仅接受仍有有效商家身份、已启用且公开发布的店铺。保存收藏当时的公开名称和 Logo；可用店铺读取当前公开版本，下线、停用或身份失效时只展示已保存名称／Logo及不可用状态，仍可移除。不读取私有草稿、联系方式或账号名，不把“收藏商家”当作关注通知订阅。商家账号删除时级联移除记录。

范围：无匿名足迹、批量收藏、数量徽标或自动清空收藏；两类收藏互不联动，均不自动写入 AI 偏好，也不改变商品足迹；收藏无人工数量上限，分页读取。列表与详情壳可匿名打开，私有内容须认证。

既有卡片操作规则：精选／采购卡片收藏按钮固定于主操作行，与采购、预览、详情及溯源互不触发；移除遮挡按钮的悬浮说明和整卡采购。详见[卡片操作分层](../../card-interactions.md)及[验证记录](../../../../evidence/2026-10-18-card-actions/verification.md)。该布局规则不改变收藏后端及足迹保留。

本轮0.2.1仅统一当前金额引用与商家收藏验收版本；不改变收藏／足迹业务，也不将新AC写成已通过。
