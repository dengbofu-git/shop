# 商品详情购买摘要

2026-10-22，web 0.27.3。只调整买家商品详情展示与现有规格定位，不修改商品价格、库存、订单或结算接口。

- 图片与购买摘要用自适应双栏；1000px以下改为单栏，价格及服务承诺按内容自然增高。数量、购买、采购车、联系商家与收藏分组排列，窄屏可以换行；手机搜索框占完整一行，避免横向溢出。
- 参考价格读取详情接口原价，展示当前侧栏币种代码和两位小数。使用商品采购目录既有参考展示比例：CNY 1、USD 0.14、AED 0.51、SAR 0.52、EUR 0.13；当前商品详情侧栏提供USD、AED、SAR。异步响应返回时读取当前选项，切换币种只更新显示，不写回价格。
- 匿名采购车从接口原价取数，保留小数并提供原始unit_price，不再解析显示金额；最终结算继续由既有交易接口决定。本次不统一全站历史汇率／计价语义。
- 净含量、净重及对应英／阿标签为当前SKU只读文本，只显示当前值，不生成输入框或选择按钮。保留其属性ID供现有SKU组合解析；其他销售属性继续选择并定位SKU，商品管理员的编辑功能不受影响。
- 无有效价格显示“—”，不伪造默认299或零价。属性和商品名称以文本渲染。

验证见[记录](../../evidence/2026-10-22-product-detail/verification.md)。

## 数量控件补充（web 0.27.5）

减号、数量输入及加号位于同一圆角边框内，中间可直接键入整数；提供明确的键盘焦点、按钮分隔及可访问名称。键入时允许暂时清空；失焦、回车及购买／加车入口使用同一校正逻辑：有库存时限制在1至可用库存，空值或非整数恢复上次有效数量，越界值调整到边界；无库存时显示0并禁用三个控件。方向键上下按1步进，到达边界时禁用相应按钮。服务端仍负责最终库存和交易校验，本次不改接口或库存数据。详情脚本移除原先的委托加减事件，避免同时触发两套步进。
