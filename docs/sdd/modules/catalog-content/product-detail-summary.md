# 商品详情与可购买性（现行）

规格0.2.0，2026-10-23，R06已确认，读取集合拆分尚待实现。

公开详情读取集合须校验商品仍公开展示、商家有效和字段可公开；零库存不阻止读取商品介绍。可购买集合在此基础上增加上架可售和正可用库存。推荐、加车及下单仅消费后者；下架／隐藏／私有商品继续按访问策略拒绝，不泄漏存在性。

缺货时保留可靠名称、规格、公开属性、基础价及“暂不可购买”提示，禁止购买动作；默认不自动替换推荐商品。用户明确要求替代品才发起新推荐。不得因拆分集合而暴露成本、任意私有属性或取消服务端最终校验。网站、Agent及本地MCP应引用同一公开规则，具体接口字段在技术设计中确定。

验收：已公开缺货详情可读但不能买，隐藏详情不可见，缺货追问保留对象，库存恢复重新校验，商品与商家跨范围拒绝。当前Agent详情仍通过available_products读取，为已登记差异。本轮无功能验收。

## 保留的布局与数量规则


- 图片与购买摘要用自适应双栏；1000px以下改为单栏，价格及服务承诺按内容自然增高。数量、购买、采购车、联系商家与收藏分组排列，窄屏可以换行；手机搜索框占完整一行，避免横向溢出。
- 参考价格读取详情接口原价，展示当前侧栏币种代码和两位小数。比例和支持币种统一读取tea_saas/currency.json，默认CNY；异步响应返回时读取当前选项，切换币种只更新显示，不写回价格。
- 匿名采购车从接口原价取数，保留小数并提供原始unit_price，不再解析显示金额；最终结算继续由既有交易接口决定。历史币种及参考换算按现行人民币金额规格执行。
- 净含量、净重及对应英／阿标签为当前SKU只读文本，只显示当前值，不生成输入框或选择按钮。保留其属性ID供现有SKU组合解析；其他销售属性继续选择并定位SKU，商品管理员的编辑功能不受影响。
- 无有效价格显示“—”，不伪造默认299或零价。属性和商品名称以文本渲染。

既有布局验证见[原始记录](../../evidence/2026-10-22-product-detail/verification.md)，不覆盖本轮缺货详情新规则。

## 数量控件

减号、数量输入及加号位于同一圆角边框内，中间可直接键入整数；提供明确的键盘焦点、按钮分隔及可访问名称。键入时允许暂时清空；失焦、回车及购买／加车入口使用同一校正逻辑：有库存时限制在1至可用库存，空值或非整数恢复上次有效数量，越界值调整到边界；无库存时显示0并禁用三个控件。方向键上下按1步进，到达边界时禁用相应按钮。服务端仍负责最终库存和交易校验，本次不改接口或库存数据。详情脚本移除原先的委托加减事件，避免同时触发两套步进。
