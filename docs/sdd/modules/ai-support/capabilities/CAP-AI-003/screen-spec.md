# 买家客服订单查询页面状态

目标规格0.3.0，2026-10-23；使用现有buyer_support.html，不重做技术栈。

| 场景 | 交互 |
| --- | --- |
| 待输入／发送中 | 明确当前咨询，防重复，输入法组合不发送；Enter发送、Shift+Enter换行 |
| 完整结果 | 展示业务事实及匿名订单位置；新回复每笔提供查看按钮，定位至本人订单页中的对应订单。查询时间保留结构化字段，正文不重复显示近期笔数上限、要求提供订单号或ISO时间串；保留必要状态时效提示 |
| 部分完成 | 明确“部分完成”，逐项显示完成／失败／跳过；保留独立成功结果，不把失败订单当成功 |
| 可选偏好不可用 | 普通推荐继续时提示本次未使用已保存偏好，不能显示“没有偏好” |
| 明确偏好任务失败 | 说明偏好服务暂不可用，可重试；其他独立任务按部分完成显示 |
| 纯订单不可见404 | 统一未找到可查询订单，不泄漏存在性，不显示无关本人订单 |
| 无订单／澄清 | 明确空结果或具体对象缺项，不能伪装服务故障 |
| 当前页序号追问 | 页内位置与已展示顺序绑定；下一页替换当前映射，失效／歧义时重新选择 |
| 历史／成功重放 | 标明原回答时间及非实时；重试同请求不刷新状态，新追问才重新查 |
| 401／403 | 登录或权限提示，清理本标签页不匹配的身份显示 |
| revision／request_id冲突 | 恢复当前会话或创建新动作，不能覆盖新轮次 |
| 网络／5xx | 保留输入及同一未知结果请求编号重试；新问题新编号，不一直显示上一轮已保存 |

分页先保持当前可读结果，加载失败可重试；迟到响应不覆盖新选择。历史、移出、撤销及隐藏列表恢复按[历史规格](../../conversation-history.md)，仅本浏览器显示状态，不提供数据库删除。

2026-10-26订单查看增量：按钮使用服务端生成的本人订单匿名引用；订单页只在当前本人可见订单中精确匹配，并提供“查看全部订单”。不可访问或已隐藏时显示不可查看，不自动跳至其他订单。此引用用于页面定位，不授权访问，也不等于已实现聊天内“第二笔”的R09位置映射。旧记录缺少可靠引用时不猜测补链。
