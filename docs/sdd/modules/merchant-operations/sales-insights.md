# 商家首页真实销售洞察

日期：2026-10-22；supplier 0.3.3、web 0.27.1。归属 CAP-MER-002／FEAT-013，保留现有能力阶段。本规范替代首页“市场洞察与数据分析”原有演示展示，销售资格仍遵循[商家与平台统一销售口径](../platform/sales-reconciliation.md)。

## 范围与来源

首页提供“本店销售洞察／我的销售数据／行业趋势”三个页签。现有订单没有可靠的结构化国家／地区字段，也没有买家口感偏好、行业出口统计、竞品采样及政策来源模型，不能据此提供“中东市场”或行业结论。普通商家发布的资讯不等于经核验的政策或行业数据。

新增 `GET /v1/supplier/insights`，只返回当前商家数据，忽略客户端商家 ID。有效账号的统一权限入口必须指向商家工作台；未登录／停用返回 401，买家／平台角色返回 403，非 GET 返回 405。响应禁止缓存。读取不修改账号、订单、商品或其他业务数据，不新增 Migration。

本接口独立于既有 `/v1/supplier/analytics` 的推算型地区和辅助指标；本轮不改造数据中心整页及其他模块，旧接口中的推算字段不能作为本区域的数据源。

## 统计口径

- 周期为查询时间前365天，起始时刻包含，结束时刻排除，按订单下单时间归集，排除未来订单。
- 订单资格复用 `orders.analytics.sales_eligible_orders`：标准单状态2/3/4；试单2/3/4/5/6/8；预售定金、尾款均已支付且未取消。待付款、仅定金、已退货试单和已取消预售排除。
- 按订单明细 `merchant_snapshot` 确认成交商家；历史快照为空时，沿用当前 SKU 商品商家回退。快照不为空时，商品转移商家不能转移历史销售归属。本接口不补写快照。
- 金额为本店商品明细成交单价乘件数之和，不含订单头金额、其他店铺商品或运费，固定以 CNY 表达。金额以十进制定点计算并输出两位小数字符串。
- 商品按当前 SPU ID 和名称分组：合并多个 SKU 规格，同名但不同 ID 的商品保持独立。名称及商品归类来自当前商品表，成交单价、数量与商家归属使用订单记录；不把规格名当商品名。

## 各页签

| 内容 | 实际来源与排序 | 展示规则 |
| --- | --- | --- |
| 热销商品 TOP5 | 本期已付本店明细按商品汇总，件数降序、金额降序、商品 ID 升序 | 显示商品名与件数；条形宽度按件数相对榜首计算 |
| 成交单价分布 | 历史成交单价分为 `<80`、`80≤p<120`、`120≤p<280`、`p≥280` 元，互不重叠 | 按购买件数加权，件数为销售单位而非茶叶重量；百分比保留1位，可有四舍五入差异；未付订单不计入 |
| 近6个自然月已付订单 | 上海时区当前月及前5个自然月，与本期已付明细集合求交 | 每月订单去重、金额按本店明细求和；当前月截至查询时间；显示完整年／月、笔数、两位小数金额 |
| 商品销售额 TOP5 | 金额降序、件数降序、商品 ID 升序 | 显示两位小数 CNY 金额，条形宽度按金额计算 |

价格分布仅统计件数为正、成交单价非负的明细；异常明细数量通过 `excluded_lines` 返回并在页面披露，不静默伪装为价格样本。该过滤不重写交易数据，也不改变其他销售聚合口径。零有效样本的百分比为 `null`，界面显示暂无记录，不能画成有市场意义的零占比。其他区间在有样本时可真实显示0件／0%。

## 未接入项目

模板及后端均保留 TODO，移除原固定口感标签、45%／68%／33%、包装类型混入价格区间、模拟地区金额、出口／竞品假图及无来源政策通知：

- 口感偏好：`taste_preferences=null`，待接入有来源的结构化偏好数据。
- 地区销售：`regional_sales=null`，待接入可靠国家／地区字段；禁止按订单号哈希或自由地址猜测国家。
- 行业出口、竞品及政策：`industry` 中对应字段均为 `null`；行业页明确显示尚无已接入、可核验来源，模板注释列出待补数据要求。

页面同时说明这些项目未接入，不为未知项编造数字或内容。已有模拟账号的订单如果真实存储在当前数据库，按同样业务规则计入；界面不宣称它们是外部市场样本。

## 加载与交互

统计与工作台其他区域独立加载。首次、手动刷新、重新可见以及返回首页时获取最新结果；请求12秒超时，可以重试。加载／失败清除旧统计，不显示演示值；无订单显示真实零总数、空排名和零月份。过期请求、离开页面后的响应以及切换账号前的数据不得覆盖当前账号。

支持中文、英文、阿拉伯文、窄屏及 RTL。页签使用 `tablist/tab/tabpanel`，支持方向键、Home、End；隐藏页签不会混入当前可见内容。所有商品名称使用纯文本渲染，条形范围限制为0至100%。

### 价格分布展示（web 0.28.2）

卡片显示“人民币 CNY”，区间行明确“元 / 件”（外语使用CNY / unit对应文案），与历史成交人民币口径一致，不跟随商品目录的参考换算。区间以“低于80／80–120／120–280／280及以上”表达，说明含起始价、不含结束价，最后一档无上限。每行区间与占比、件数对齐，下一行完整比例条；百分比按语言格式显示，零件数保留真实零值。后台统计与边界不变。
