# 商家数据中心异步渐进展示

日期：2026-10-19；web 0.20.0。归属 CAP-MER-002／FEAT-013，保留现有能力阶段。当前行为替代此前整页加载遮罩；底层统计规则仍见[销售额核对](../platform/sales-reconciliation.md)。

## 问题与范围

旧页面将外部 ECharts 脚本加入 `defer` 队列，后续本地初始化须等待它；初始化又先等待图表库才请求统计，最后全部绘制完成才撤销遮罩。这形成可从源码确认的串行等待链。本次优化前端调度和展示，不改 `/v1/supplier/analytics`、鉴权、数据库、指标定义或统计周期；没有测量真实网络／业务库耗时，不声称后端聚合本身提速。

## 当前行为

- 页面先显示指标卡框架与图表区域，局部显示加载提示，不遮挡工作台导航。
- 本地初始化独立运行；统计接口与异步图表脚本并行启动。统计返回后立即显示核心指标和辅助指标，不等待图表库。
- 五张图表分别在浏览器空闲任务中绘制；每张有加载提示和 `aria-busy`，单张失败不隐藏其他图表或已返回指标。
- 周期选择、刷新数据、可播报的加载状态和重试按钮位于公共工具栏，独立页面和工作台 iframe 内均可使用。
- 图表库优先加载同源静态文件 `vendor/echarts/5.4.3/echarts.min.js`；本地文件失败／超时后，依次回退至原有 bootcdn、jsdelivr 两个 CDN。每个来源最多等待 5 秒，本地成功时不请求外部来源。总失败时保留统计指标，图表显示失败提示；点击重试只重试图表，复用本次统计响应。
- 统计请求 12 秒超时，超时中止请求并显示可重试错误；接口失败时保留“—”和错误提示，不将失败数据画成零成交图表。点击重试重新请求统计。
- 切换周期清除旧显示、取消上次请求，按新周期重新加载；旧响应及旧空闲绘图任务均不能覆盖新周期结果。已有图表在重新加载和离开页面时释放，浏览器往返缓存恢复后重新初始化。
- 不引入跨账号缓存、持久化销售数据、后台任务队列或新的统计接口。

## 2026-10-20 本地图表库修复

截图中的五张图表均报“图表库加载失败”，原实现只有外部 CDN 来源。web 0.23.2 将原固定版本 ECharts 5.4.3 随前端静态资源交付，更新初始化脚本缓存标记并移除 CDN 预连接。npm 官方包的 SHA512 integrity 校验通过，保留 LICENSE、NOTICE 和附带的 d3 许可；`source.json` 记录下载来源与文件 SHA256。统计接口与业务口径沿用原契约。
