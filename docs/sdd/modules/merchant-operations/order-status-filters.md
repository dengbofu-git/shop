# 商家订单分类与安全动作

规格0.2.0，2026-10-23，CAP-MER-001。状态及库存唯一规则见[交易预留](../trade/stock-reservations.md)，本页只定义本商家展示、过滤和动作入口。

列表和金额只包括本人商家明细，归属优先购买快照。支持全部、待付款、待发货、待收货、已完成及已关闭；子类型状态使用交易域文字和服务端映射，不能套用普通status数字。分类计数、列表和看板用同一过滤规则。

支持独立merchant_orders.html及工作台embed，filter=unshipped/unpaid等保留URL上下文；原客户端本地分类与后端按状态读取均不得越过商家范围。实际子类型标签可扩展，零项仍能理解当前分类。错误保留旧数据显示刷新失败，成功重读之前不执行旧动作。

动作依据服务端can_ship/can_delete等能力标记；缺标记不启用。can_delete及原delete路径为兼容名称，界面表达“取消订单”，仅未付款普通订单可取消并保留交易记录；不得删除完成订单。发货走统一服务，混合历史订单提示平台处理并拒绝整单动作；试单／预售仅按独立状态及付款条件发货，重复请求成功且只扣一次。

操作中防重复，成功后读取新状态和数量；失败保持分类并给具体错误。收货信息以文本输出，本店查看不等于可以送入Agent或公开遥测。宽表局部横向滚动，键盘与窄屏可使用。

验收：购买后商品转店仍按快照隔离；另一商家读写拒绝；混合单不变；全款预售／试单推进各自子状态；重复发货只一次流水；取消记录保留；筛选及看板一致。原日期测试只对应原源码，本轮没有执行新行为验收。
