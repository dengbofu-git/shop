# 买卖双方站内咨询

日期：2026-10-21。能力 CAP-MER-006，功能 FEAT-037；业务归 MOD-MER，参与端为买家与商家，身份规则引用 MOD-IAM。实现模块 engagement，页面归 web。依据本轮用户确认的方案实施；本地验证不等于业务环境已迁移或发布。

交付更新：[版本说明](../../../版本说明-2026-10-21.md)与[同步main后的交付证据](../../evidence/2026-10-21-engagement-delivery/verification.md)记录本次源码及验证；不将历史截图或PR创建视为已部署证明。

## 入口与会话规则

- 商品详情“联系商家”携带 sku_id；订单商品“联系商家”携带 order_item_id。买家消息中心与商家工作台“买家咨询”保存会话和未读；商家页面可在工作台 iframe 打开。
- 一个买家与一个商家唯一一个会话。GET resolve 只定位，不建立空会话；买家发送第一条有效消息时在同一事务创建会话和消息。商家只能回复已有会话。
- 身份只取当前标签页 JWT 和数据库有效权限。活跃买家与活跃商家可以访问；运营账号不能使用买卖双方会话接口。停用、角色变化及跨账号／跨商家访问均由后端拒绝。
- 商品关联的商家由服务端查询，订单关联的商家使用购买快照。页面提供的 merchant_id 仅可作为普通店铺目标，或与服务端结果一致；不允许向当前会话夹带其他店铺商品、其他买家订单。
- 旧订单无可信快照不关联订单卡片，返回 HISTORY_NOT_VERIFIED；仍可通过商品或店铺发起普通咨询。不会根据当前商品归属批量补造历史购买归属。
- 消息为 1～2000 字纯文本，可附服务端生成的商品或订单卡片；订单卡片只投影订单号、商品与规格，不包含地址、收件人、手机号。商家看到脱敏买家名及独立会话。
- 现有 support_ai、merchant_ai、长期偏好和知识库不参与，不自动向模型传送站内咨询。

## 接口契约

统一前缀 `/v1/engagement/`，同源请求；`Authorization: Bearer <当前标签页 token>`。成功响应 `{code:200,data:...}`，新增记录 HTTP 201，重放 HTTP 200；错误响应 `{code:<HTTP>,error_code,error}`。响应 `Cache-Control:no-store`。

| 方法与路径 | 输入 | 输出／约束 |
| --- | --- | --- |
| GET identity | 无 | buyer／merchant，前端据此保护页面 |
| GET conversations/resolve | sku_id、order_item_id、merchant_id，商品与订单不能同时指定 | conversation_id 或 null、商家公开名与关联卡片；买家专用 |
| GET conversations | page，正整数 | 每页20会话、总数、全部本人会话 unread_total；按最后消息时间、ID倒序 |
| POST conversations | text、request_id、一个关联目标 | 买家首条消息或已有会话的消息；事务失败不残留空会话 |
| GET conversations/{id}/messages | before 或 after，互斥正整数 | 每批最多30条，升序、has_more、对方已读位置；无游标取最新30条 |
| POST conversations/{id}/messages | text、request_id，可选 sku_id 或 order_item_id | 参与者发送；无关联参数时普通文字 |
| POST conversations/{id}/read | message_id | 只能标记本会话已有消息，已读位置单调递增 |

会话／消息／订单对象不属于当前用户时返回404。字段错误400；认证401／角色403；目标停用或上下文冲突409；每个发送者每分钟最多30条新消息，超限429。已成功 request_id 重放不消耗限额。

## 持久化与并发

Conversation 保存双方账号、双方已读位置和最后消息时间，数据库唯一约束 buyer+merchant。Message 保存 conversation、sender、text、服务端 context、request_id、请求指纹和时间；sender+request_id 唯一，conversation+id 建索引。

发送事务先锁当前发送者，再锁既有会话；首条消息在锁买家后 get_or_create 唯一会话。相同标识、相同原始关联参数和正文返回原消息；换正文、换目标返回409。身份与归属仍须检查，不允许依靠重放扩大访问范围。已读更新锁会话并做条件更新，不因其他标签页的旧请求倒退。

## 页面状态

桌面会话列表／聊天／关联内容三栏；中等宽度关联区置底；640px以下列表与聊天分层切换。首条消息未发送、未选会话、加载、空列表、失败重试、发送中、历史分页分别展示。

聊天约4秒增量轮询；失败指数退避至30秒。页面隐藏或商家 iframe 未展示时暂停主动聊天轮询；全站未读徽标约30秒刷新。已读只在页面可见、获得焦点且接近消息底部时推进；消息列表返回的未读数同步徽标。当前会话草稿及待重试标识仅存本人标签页 sessionStorage。中／英／阿拉伯语及RTL沿用对应端语言偏好。

首期不提供图片、附件、语音、在线状态、消息撤回、批量群发、外部消息推送和自动翻译。

## 验收与启用

跨买家／商家消息及已读拒绝；伪造卡片拒绝；历史正反向分页不重不漏；重复首条消息只建一个会话；并发首次发送只保存一条消息；已读不倒退；商家回复后买家可见；AI会话数量不改变。见[本轮验证](../../evidence/2026-10-21-engagement/verification.md)。

engagement 迁移依赖 orders 新增快照迁移。业务库未迁移；启用前须单独授权业务数据库迁移和服务更新。轮询在高并发下的容量尚未做负载测试，WebSocket为后续可选演进。
