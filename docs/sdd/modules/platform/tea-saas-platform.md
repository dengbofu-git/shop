# 产品定位、三类角色与实现范围

规格0.2.0，2026-10-23。产品名称各语言统一tea_saas，授权以根LICENSE和README为准，不在本规格重新解释许可条款。

## 角色

| 产品角色 | 允许范围 |
| --- | --- |
| 管理员 | 按实时平台权限访问用户管理、总览、Agent配置和监控 |
| 商家 | 本店商品、库存、订单协作、咨询、经营指标与结算记录 |
| 买家 | 采购、本人订单／地址／收藏、客服及本人显式偏好 |

运营、财务或客服岗位名称在本项目属于管理员的内部权限配置，不能据名称新增产品角色或授予代查买家订单。super_admin/admin/customer_service/finance/supplier等既有RBAC码继续兼容，页面不可见不替代服务端鉴权。

## 当前边界

技术为Django多App单体与模板／JavaScript多页面；工程包为tea_saas，物理目录和数据库／环境名称不自动改名。历史Migration和原始证据保留。SaaS是定位，未实现租户计费或订阅不能表述为已交付。

普通订单在线结算、预留与付款事实按交易规格；试单／预售保留已定义读取和历史条件发货，不宣称全部生命周期。经营指标只用可核验本店／平台事实，无可靠来源的地区、口感、行业／政策内容保持未接入；结算展示不等于资金清结算。

买家Agent为受控只读工具，商家助手仍仅入口和状态接口，不能因存在欢迎页就开放聊天／文件导入或经营写操作。管理员知识库网页上传入口已移除，现有CLI导入与RAG配置独立管理。多语言导航与内容翻译范围分开标记。

当前源码、隔离证据、本地启用与远端部署分别登记。规则范围和待实施清单见[审查决定](../../rule-review.md)及[当前状态](../../product/current-state.md)。
