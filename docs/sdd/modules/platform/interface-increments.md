# 采购与经营页面补充交互

## 2026-10-22 买家账户菜单（web 0.29.1）

头像下拉菜单以按钮实际高度定位，预留20px间距，面板各选项采用独立圆角和间距，退出单独分隔。仅与当前路径一致的个人信息或账户设置项使用`aria-current="page"`，避免两项同时高亮。展开／收起使用透明度和位移动画，悬停或键盘聚焦平滑变色并轻微移动，RTL反转位移方向；减少动态效果偏好关闭动画。

菜单闭合时`inert`与`aria-hidden`同步，头像`aria-expanded`同步；支持头像方向键打开、选项方向键／Home／End移动、Escape关闭并返回头像、点击或聚焦外部关闭。不改变资料保存、密码修改和退出登录行为，样式限定买家顶部栏。

验证：以当前Django共用头部及真实工作台脚本在独立本地预览中检查。个人信息路径只高亮个人信息，设置路径只高亮设置；桌面菜单顶部约74px，位于顶部栏底边约69px的下方，无交叠；方向键、聚焦过渡、Escape及外部点击均通过。390px与阿拉伯文下菜单边界在视口内，原顶部栏其他内容的窄屏溢出未纳入本次修复。预览未连接账户API，未操作真实资料或退出登录；鼠标悬停样式已设置，浏览器操作验证以键盘聚焦的同款过渡为准，未单独测量鼠标悬停动画帧。

所有含工作台脚本的模板已通过隔离设置渲染，CSS静态资源查找、Node脚本语法、模块归属及`git diff --check`通过。未新增自动化测试或执行全站回归。截图位于忽略目录`.scratch/account-menu-20261022/desktop.png`，临时预览页及服务验证后关闭。未提交、推送或部署。
