## 2026-10-19 数据中心加载层位置修复（web 0.19.1）

数据中心 `operations_dashboard.html` 的加载层统一使用 `position: fixed; inset: 0`，在当前可见视口居中；商家工作台内嵌时以 iframe 视口为准，独立打开时以页面视口为准。移除按 `.dashboard-root` 长页面绝对定位的覆盖规则，避免加载提示需要下拉才能看见。保留图表请求、完成退出及失败提示逻辑，并更新样式缓存参数。

本次验证覆盖独立／内嵌参数下的 Django 模板渲染、加载样式静态资源及定位覆盖规则、模块归属与 Diff 空白检查；未做浏览器视觉验收。

后续 web 0.20.0 改为[数据中心异步渐进展示](../merchant-operations/data-center-loading.md)，当前数据中心不再使用整页加载遮罩；以上固定居中修复为前一版记录。
