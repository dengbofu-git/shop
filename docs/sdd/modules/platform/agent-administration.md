# Agent 运营管理与知识库入口

2026-10-18当前实现对账，能力 CAP-AI-004／CAP-KNOW-002，代码由 admin_panel、support_ai、ai_storage 与 web 共同提供。本增量来自“管理员端”“rag”和MCP相关聊天，复用 [平台交易总览外壳](trading-overview.md)。

## 访问和导航

平台有效角色加system_config控制Agent管理API；不能因为商家有商品权限或买家有data_view就放行。账号管理、总览与Agent API各自校验权限，嵌入页面或导航可见不替代服务端鉴权。统一外壳的Agent导航进入原管理内容，直达地址和embedded模式按已有总览规格处理。

## 模型和检索配置

页面提供模型发现、思考模式、知识检索和本地重排序参数、运行配置修订及变更记录；后端每次请求取生效配置快照，不能用.env默认值推断实际模型。重排序健康接口反映模型可用性，不保证历史评测质量问题已经解决。

四个布尔开关为启用重排序、异常回退、启用监控和导出Collector。只有点复选框本体才切换；文字和中间留白不触发。保持aria-labelledby／describedby的可访问名称，不以扩大label点击区域重引入误选；键盘仍通过checkbox操作。该修复未改变默认值或后台权限。

## 知识库提交占位

“提交知识库文件”入口指向Agent页知识库区域，显示暂未开放，上传按钮禁用。没有上传、文件解析、审核、发布或向量入库HTTP接口，不读取或上传用户文件。现有CLI知识导入命令继续独立管理，不能根据按钮存在认定文件入库已交付。

## 监控与日志

现有OTel记录节点耗时、模型调用、Token和错误等安全属性；是否导出由配置决定。平台页面能看监控不表示可以读取任意买家问题、订单号或商家私有文件。终端预览的脱敏JSONL另属开发记录，保留和访问策略仍需单独确认。

## 验证边界

管理端嵌入的已有合成账号浏览器材料见 [平台总览证据](../../evidence/2026-10-18-platform-overview/verification.md)，权限增量见 [统一登录](../identity/unified-login.md)。四开关修复已有模板／样式改动，但没有独立完整交互自动化证据；本次仅核对源码，不将旧监控、模型ready、页面截图或其他模块的测试数字当作当前全流程通过。
