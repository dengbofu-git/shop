## 产品及数据边界

物理工作区名称以本机路径为准，工程及产品使用 `tea_saas`。三类产品角色为管理员、商家、买家，内部 RBAC 码不另增产品角色。当前资产为 Django 多 App、模板／JavaScript 多页面、MySQL 业务与会话、PostgreSQL 知识及偏好、Redis 采购车。模型 Agent 数据入口为 MCP，领域服务继续负责数据库访问。

SaaS／跨境为已有产品定位，不证明租户隔离、订阅计费、报关、国际收款或完整跨境履约已交付。不能因实现尚不完整否定已确认目标，也不能将定位当作已实现功能。
