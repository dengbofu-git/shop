- JOURNEY-TRD-001：选品→下单→支付→发货→物流→收货。当前只有部分路径接通；不能从旅程目标反推整条运行闭环已实现。
- JOURNEY-AI-001：买家客服查询本人订单，具备现有读取／会话／重放，仍有已确认目标差异。
