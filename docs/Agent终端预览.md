## 启动

在 PowerShell 运行：

```powershell
cd E:\django\dadashop
.\support_ai\preview.ps1
```

或者直接调用项目 Python：

```powershell
& E:\miniconda\envs\dadashop\python.exe -X utf8 -u manage.py agent_preview
```

出现 `你 >` 后输入问题并回车。无需打开页面，也无需 Django HTTP 服务或 Redis。
仍需当前配置的 MySQL、DeepSeek；知识问答另外需要 PostgreSQL、Ollama 和按配置启用的重排序服务。
输入会调用当前模型服务，现有个人信息脱敏规则在调用前生效；避免输入不必要的敏感内容。

## 会话操作

| 输入 | 用途 |
| --- | --- |
| 普通文字 | 调用真实 Agent；显示回答、有序意图、任务状态、耗时及模型 Token |
| `/plan` | 查看上一成功轮的结构化任务计划 |
| `/rag` | 查看上轮知识查询、各路命中、补检原因及最终片段ID |
| `/history` | 查看下一轮使用的脱敏上下文 |
| `/config` | 查看当前模型、思考模式、配置修订号、重排序和日志路径 |
| `/new` | 清空本会话上下文及订单选择，新建日志文件 |
| `/help` | 显示帮助 |
| `/exit` 或 `/quit` | 退出；也支持 Ctrl+C |

默认每轮重新读取运营配置，复用现有有限意图提取、任务模板、工具、合规、向量召回及重排序。
真实生成的回复进入下一轮上下文；与网页共用历史构建函数：最近 24 小时、最多 6 轮、助手文字最多 1500 字、历史 JSON 总预算 6000 字符。

## 买家范围与记录

默认仅查询公开已发布知识和真实在售商品，未指定买家时订单工具提示绑定账号。
本地开发者明确选择活跃买家后，才会读取其偏好、私有已发布知识及订单状态：

```powershell
& E:\miniconda\envs\dadashop\python.exe -X utf8 -u manage.py agent_preview --user-id <买家ID>
```

这是本地开发工具，依赖本机已有的数据库和模型凭据；不能作为公开 HTTP 接口或远程无鉴权终端。
不会自动读取旧会话，不创建账号，不写入客户会话、商品、订单或偏好。
每个会话单独记录到 `reports/agent-preview/*.jsonl`；字符串经现有脱敏规则处理，包含输入、补全问题、实际回复、任务计划、意图、耗时及 Token，不保存原始订单引用、密钥或整段知识候选。
失败仅记录错误类型，不把失败轮加入后续历史。脱敏规则不保证识别任意格式的个人信息。
工具失败会额外记录其名称、状态、错误类型及任务计划；合规拦截单独显示并记录 `compliance_blocked`，避免将工具成功等同于回答通过。

默认隔离运营监控数据；加 `--telemetry` 时按运营开关写入 AgentSpan 并导出 OTel，需将这些预览调用计入监控统计。默认日志可用 `--log-dir` 更改。

## 无交互调用

重复传入 `--message` 可以在同一个临时会话中连续输入；`--json` 输出完整 JSONL 结果：

```powershell
& E:\miniconda\envs\dadashop\python.exe -X utf8 -u manage.py agent_preview --message '推荐两款绿茶' --message '介绍第一款商品' --json
```

本入口直接调用当前 Agent，便于定位意图、工具和多轮行为；它不经过网页身份验证、HTTP 限流或客户会话提交路径。
