# 买家 Agent 100条合成测试用例

日期：2026-10-19，Asia/Shanghai。先冻结用例，再运行真实模型。所有问句、个人信息、商品和知识片段均为合成数据，不读取真实买家历史。

交付格式说明：本文可读展示的行尾空白已规范化。超长及纯空白用例的精确输入和长度以冻结 JSON 数据集为准，原始数据未修改。

## 范围和判定

七类主场景共100条。相同session的用例按编号执行，前轮实际回答构成后轮上下文；独立session互不继承。
每条为一次用户输入，共100次输入，不将100个独立单句冒充上下文测试。
业务图使用原LangGraph和真实模型，商品仅来自隔离SQLite合成目录；知识检索以固定合成片段或指定故障替代。因此可评价语义规划、工具交接与回答，但不代表生产知识召回质量。
超长场景通过真实HTTP视图的前置校验；应拒绝的请求不发送模型。其余场景走业务图，不能据此声称完成浏览器或全部HTTP链路验收。
“违禁指令”指越权、泄密、写库请求及伪造系统指令，不假设项目已有敏感词表或自动截断功能。输入边界使用完整原文，不在测试器内预先截短。
自动判定检查结构化任务、SKU身份、价格、证据来源、敏感值是否进入提示词和回复等；回复语言启发式与拒绝措辞不能证明全部语义正确，另列人工复核。

## 合成商品基准

绿茶、红茶、白茶、乌龙茶、黄茶、黑茶各有三个在售SKU，价格10/30/80 USD、11/31/81 USD依次递增；另建相似名称礼盒、Pro、英文名称、下架和零库存商品。单规格与相似名称不能被视为同一SKU。
