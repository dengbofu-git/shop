# Dadashop（茗越山关 9710）项目接手指南

面向新合作开发者的业务与代码导航。**环境与依赖请以 [环境配置.md](./环境配置.md) 为准**（Conda、MySQL、Redis、`.env` 全量说明）。

---

## 1. 项目简介

- **技术栈**：Django 3.2 + MySQL + Redis + 多页面 jQuery/原生 JS 前台。
- **角色**：中东买家、茶企商家、平台运营；扩展模块含 9710 报关、运营数据中心、AI 客服等。
- **API**：`/v1/<app>/`，页面路由见 `dadashop/urls.py`。

---

## 2. 快速开始（摘要）

完整步骤见 **[环境配置.md](./环境配置.md)**。

```powershell
conda create -n dadashop python=3.9 -y
conda activate dadashop
pip install -r requirements.txt
copy .env.example .env
# 编辑 .env 后：
python manage.py migrate
python manage.py seed_rbac
python manage.py create_super_admin
python manage.py runserver 127.0.0.1:8000
```

访问：http://127.0.0.1:8000/login.html

---

## 4. 目录与开发约定

- **页面路由**：`dadashop/urls.py`
- **认证**：`POST /v1/users/login`，前端 `client/static/js/auth-storage.js`
- **平台运营 API**：`/v1/admin-panel/users`（需 `goods_manage` 权限）
- **注册**：`register_sms.html` + `register-portal.js`，`register_as=buyer|merchant`
- **静态资源改版**：模板中 JS/CSS 建议带 `?v=日期-说明` 防缓存
