# Dadashop 开发与运行环境配置

本文说明在新机器上搭建 **Python / Conda、MySQL、Redis、环境变量** 并完成首次启动。与业务接手指南配合阅读：[项目接手指南.md](./项目接手指南.md)（若尚未创建，以本文件为准完成环境即可）。

---

## 1. 环境总览

| 组件 | 版本/说明 | 是否必需 |
|------|-----------|----------|
| Python | **3.9.x**（见 `requirements.txt` 文件头注释） | 是 |
| MySQL | 5.7+ / 8.x，字符集建议 `utf8mb4` | 是 |
| Redis | **127.0.0.1:6379**，DB `0`（默认缓存）、DB `1`（购物车） | 是 |
| Conda | 推荐，环境名 `dadashop` | 推荐 |
| 支付宝 PEM | `app_key/alipay_public_key.pem`（仓库内公钥）；应用私钥在 `.env` | 支付链路需要 |

外部服务（邮件、容联云短信、微博 OAuth、AI 客服、支付宝）在本地可通过 **Mock / 占位** 先跑通页面与大部分 API；见 [第 5 节](#5-环境变量-env)。

## 2. 安装 Python 依赖

项目仅维护 **`requirements.txt`**（已移除与之间功能重复的 `environment.yml`）。

### 2.1 使用 Conda（可选，Windows / macOS / Linux）

```powershell
cd e:\django\dadashop
conda create -n dadashop python=3.9 -y
conda activate dadashop
pip install -r requirements.txt
```

更新依赖：

```powershell
conda activate dadashop
pip install -r requirements.txt
```

### 2.2 使用 venv + pip

```powershell
cd e:\django\dadashop
py -3.9 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2.3 依赖说明

- **Django 3.2.12** + **PyMySQL**：在 `dadashop/__init__.py` 中 `install_as_MySQLdb()`，无需单独安装 `mysqlclient`。
- **django-redis**：会话/购物车等缓存；地址写死在 `dadashop/settings.py` 的 `CACHES`，默认 `redis://127.0.0.1:6379/0` 与 `/1`。
- **langchain / langgraph / langchain-openai**：买家智能客服（`support_ai`）。
- **python-dotenv**：启动时加载项目根目录 `.env`。

## 3. MySQL

### 3.1 创建数据库

```sql
CREATE DATABASE dadashop CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'dadashop'@'localhost' IDENTIFIED BY '你的密码';
GRANT ALL PRIVILEGES ON dadashop.* TO 'dadashop'@'localhost';
FLUSH PRIVILEGES;
```

`.env` 中 `DB_*` 与上述账号、库名一致即可。

### 3.2 迁移与基础数据

```powershell
conda activate dadashop
cd e:\django\dadashop
python manage.py migrate
python manage.py seed_rbac
python manage.py create_super_admin
```

可选：

```powershell
python manage.py seed_demo_orders --merchant <茶企登录用户名>
python manage.py create_customs_user
```

## 4. Redis

1. 安装并启动 Redis，监听 **6379**。
2. Windows 可用 WSL、Memurai、或官方移植版；开发机需保证 `127.0.0.1:6379` 可连。
3. 未启动 Redis 时，依赖缓存/购物车的接口会报错——本地开发请先起 Redis。

如需改 Redis 地址，需修改 `dadashop/settings.py` 中 `CACHES` 的 `LOCATION`（当前未通过 `.env` 配置）。

## 5. 环境变量 `.env`

1. 复制模板：`copy .env.example .env`（PowerShell）。
2. **不要** 将 `.env` 提交 Git（已在 `.gitignore` 中忽略；`.env.example` 可提交）。

### 5.1 变量一览

| 变量 | 必填 | 说明 |
|------|------|------|
| `DJANGO_SECRET_KEY` | 是 | Django 密钥，生产环境使用长随机串 |
| `DJANGO_DEBUG` | 否 | 默认 `false`；本地建议 `true` |
| `DJANGO_ALLOWED_HOSTS` | 否 | 逗号分隔，如 `127.0.0.1,localhost` |
| `DB_HOST` / `DB_PORT` / `DB_NAME` / `DB_USER` / `DB_PASSWORD` | 是 | MySQL 连接 |
| `JWT_SECRET_KEY` | 是 | 签发/校验登录 JWT |
| `ADMIN_INITIAL_PASSWORD` | 是 | `create_super_admin` 使用的 `admin` 初始密码 |
| `CUSTOMS_INITIAL_PASSWORD` | 是 | `create_customs_user` 使用的初始密码 |
| `SUPPORT_API_KEY` | 是* | AI 客服 API Key（不用客服可填占位，调用会失败） |
| `SUPPORT_MODEL` | 是 | 模型名 |
| `SUPPORT_BASE_URL` | 是 | OpenAI 兼容 API 根地址 |
| `SUPPORT_THINKING` | 否 | 扩展参数，可留空 |
| `EMAIL_*` | 是* | SMTP；不用邮件功能时仍需占位，否则启动报错 |
| `SMS_MOCK_MODE` | 是 | 本地建议 **`true`**：验证码打印到控制台，不走容联云 |
| `RONGLIAN_SMS_*` | 是* | `SMS_MOCK_MODE=true` 时可填占位 |
| `WEIBO_*` | 是* | 未用微博登录可填占位 |
| `ALIPAY_*` / `FRONTEND_BASE_URL` | 是* | 真实支付需沙箱 AppId 与私钥；仅浏览可不测支付 |
| `ALIPAY_APP_PRIVATE_KEY` | 是* | **应用私钥 PEM 字符串**（非文件路径）；公钥文件见 `app_key/alipay_public_key.pem` |

\*：Django 启动时会 `os.environ['KEY']` 读取，**缺少任一键会 ImportError/KeyError**；本地用 `.env.example` 占位即可。

### 5.2 本地最小化建议

- `DJANGO_DEBUG=true`
- `SMS_MOCK_MODE=true`
- 邮件、微博、支付宝、AI 可先填空或示例值，直到要测对应功能再改。
- 平台运营登录：执行 `create_super_admin` 后使用用户名 **`admin`** 与 `ADMIN_INITIAL_PASSWORD`。

## 6. 静态资源与支付密钥文件

| 路径 | 说明 |
|------|------|
| `client/static/` | 前端 CSS/JS/图片，`STATICFILES_DIRS` 指向此处 |
| `client/templates/` | 大部分 HTML 页面 |
| `templates/` | 邮件模板等（如 `findpassword.html`） |
| `app_key/alipay_public_key.pem` | 支付宝公钥（代码中 `open()` 读取） |
| `app_key/app_public_key.pem` | 应用公钥（按支付宝配置使用） |
| `app_key/*private*.pem` | **勿提交 Git**（见 `.gitignore`） |

媒体上传目录：`media/`（`MEDIA_ROOT`），本地访问前缀 `http://127.0.0.1:8000/media/`。

## 7. 启动与验证

```powershell
conda activate dadashop
cd e:\django\dadashop
python manage.py check
python manage.py runserver 127.0.0.1:8000
```

浏览器打开：

- 登录页：http://127.0.0.1:8000/login.html  
- Django Admin：http://127.0.0.1:8000/admin/（需 `createsuperuser` 或业务侧 `admin` 账号，二者体系不同）

PowerShell 链式命令用 `;`，不要用 `&&`（旧版 PowerShell 不支持）。

Conda 不激活时也可：

```powershell
conda run -n dadashop python manage.py runserver 127.0.0.1:8000
```

## 8. 常见问题

| 现象 | 处理 |
|------|------|
| 启动报 `KeyError: 'DJANGO_SECRET_KEY'`（或其它 env） | 确认根目录存在 `.env`，且键名与 `settings.py` 一致 |
| `django.db.utils.OperationalError` | MySQL 未启动、库未建、或 `DB_*` 错误 |
| Redis 连接失败 | 启动 Redis；检查 6379 端口 |
| 注册/登录短信失败 | 设 `SMS_MOCK_MODE=true`，在运行 `runserver` 的控制台查看验证码 |
| 平台运营 403 | `python manage.py seed_rbac` 后 `create_super_admin`，用 `admin` 登录 |
| 购物车/下单异常 | 确认 Redis DB `1` 可用 |
| CORS 报错 | 前端应通过 `127.0.0.1:8000` 同源访问；额外 origin 见 `settings.py` 中 `CORS_ALLOWED_ORIGINS` |

## 9. 生产部署注意（简要）

- `DJANGO_DEBUG=false`，`DJANGO_ALLOWED_HOSTS` 填真实域名。
- 使用独立强随机 `DJANGO_SECRET_KEY`、`JWT_SECRET_KEY`。
- Redis、MySQL 使用托管或内网地址，并考虑将 Redis URL 改为可配置（当前需改代码）。
- 配置 HTTPS、真实 SMTP、短信与支付宝生产参数；私钥与 `.env` 走密钥管理，勿进仓库。
- 关闭或严格限制 `SMS_MOCK_MODE`。
