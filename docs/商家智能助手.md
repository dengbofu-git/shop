# 商家智能助手 · v0.1.0

设计日期：2026-10-16（Asia/Shanghai）。本切片范围来自用户明确要求：商家端开放入口、初始化独立模块，沿用买家助手技术栈，暂不接入真实功能。

## 本版本范围

- 商家工作台侧栏新增「智能助手」，使用原有 iframe 面板机制打开。
- 页面 `/merchant_assistant.html` 复用 Django 模板、全站主题、原生 JavaScript 和 AuthStorage；在独立窗口也可打开。
- 页面展示欢迎空态、v0.1.0、入口状态，以及明确禁用的输入区。没有发送、上传或模拟回复。
- 新增 Django App `merchant_ai`，提供模块状态服务、URL 与商家身份保护。
- 复用已有商家／供应商身份验证约定；状态接口另检查账号已激活。
- 本版本没有会话或业务数据持久化，没有数据库迁移或新增依赖；不会调用买家客服、模型、RAG、商品、库存或媒体服务。

买家助手的商品介绍、商品推荐、售后查询、偏好与历史不移入商家模块。共享的是技术栈和认证／主题基础设施。后续编排可以使用现有 LangChain/LangGraph 依赖，0.1 不创建无业务语义的图或实例化模型客户端。

## 页面与状态

商家工作台点击「智能助手」后，侧栏选中该项，主区域加载 `/merchant_assistant.html?embed=1`；嵌入时隐藏返回工作台链接。独立页面保留返回链接。导航名称沿用工作台中、英、阿三语映射；助手 0.1 内容为中文。

| 状态 | 展示和操作 |
| --- | --- |
| 加载 | 正在确认入口状态；输入和发送始终禁用 |
| 初始化完成 | 入口已就绪、功能准备中；保持欢迎空态 |
| 未登录／认证过期 | 说明需登录商家账号，提供登录链接 |
| 非商家或未激活 | 说明入口仅面向活跃商家／供应商 |
| 请求失败、10 秒超时或合同不匹配 | 显示无法确认状态并可重试；不显示原始异常 |

页面模板是公共静态外壳，不包含商家数据；实际身份校验在状态 API 完成。输入控件在 HTML 中即为 disabled，不以 JS 成功加载作为禁用前提。

## API 合同

`GET /v1/merchant-ai/status/`

认证：沿用 `Authorization: Bearer <token>`，身份从已有 JWT 解析并重新读取用户；活跃 `merchant` 或拥有 `supplier` 角色的账号可访问，不接受客户端自报商家身份。

```json
{
  "code": 200,
  "data": {
    "module": "merchant_ai",
    "version": "0.1.0",
    "status": "initialized",
    "title": "商家智能助手",
    "message": "商家智能助手入口已开放，具体功能正在准备中。",
    "chat_enabled": false,
    "model_connected": false,
    "capabilities": []
  }
}
```

错误状态为 401（缺少或无效认证）、403（角色不符或未激活）、405（非 GET）。响应禁止缓存。没有 `/chat/` 或文件上传接口。状态 `initialized` 只表示入口模块初始化，不表示模型或业务能力就绪。
