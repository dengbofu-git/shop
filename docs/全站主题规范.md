# 全站主题规范

统一基准为 `/admin_agents.html`。所有 32 个完整业务页面通过
`client/templates/shared/system_theme.html` 在页面原样式之后加载公共主题。
买家、茶企、运营、登录注册、搜索、支付、报关和溯源共用同一套视觉变量。
Django 内置管理后台由 `client/templates/admin/base_site.html` 接入；两份邮件模板
使用相同配色的内嵌 CSS，避免依赖外部静态资源。

## 设计变量

| 用途 | 值 |
| --- | --- |
| 主色、主要操作 | `#185c3b` |
| 正文、标题 | `#17352b` |
| 次要文字 | `#6a7d73` |
| 页面背景 | `#f3f6f2` |
| 卡片背景 | `#ffffff` |
| 细边框 | `#e1e9e3` |
| 选中背景 | `#e7f2e9` |
| 卡片圆角 / 控件圆角 | `16px` / `8px` |
| 字体 | `system-ui, -apple-system, "Microsoft YaHei", sans-serif` |

## 维护入口

- `client/static/css/design-tokens.css`：共享变量及旧组件变量别名。
- `client/static/css/system-theme.css`：通用外观和旧页面适配，以 `.ds-theme` 为作用域。
- 页面正文使用 `ds-theme` 和 `ds-page-页面名称` 类，保留原有类、ID 和事件绑定。
- 新增完整页面时，在 `</head>` 前包含 `shared/system_theme.html`，并设置
  `body` 的 `ds-theme` 类和 viewport 元信息。
- 头部、侧栏、页脚片段从父页面继承主题，不重复插入完整文档结构。
- 页面原样式继续负责布局和显示状态。不要给通用卡片、表单、弹窗选择器强制
  设置 `display`，以免破坏标签页、隐藏表单和弹窗逻辑。
- 错误、待处理、删除等语义颜色保持区分。商品照片和品牌图片保留原内容。
- ECharts 绘制内容不继承 CSS，图表配色在 `operations-dashboard.js` 中同步维护。

本次修改不涉及数据库连接、账号或业务数据。
