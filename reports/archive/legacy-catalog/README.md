# 旧通用商城商品样例

`goods_data.json` 原位于仓库根目录，保存2020年的手提包／运动品牌示例，不是当前茶商品批次。当前代码和维护命令未引用此文件，本次仅按原字节归档，不导入数据库。

当前茶商品造数继续使用 `seed_virtual_tea_products` 命令，范围和数据库约束见 [虚拟商品数据](../../../docs/虚拟商品数据.md)。如需研究旧样例，复制到隔离环境；不得将旧主键直接导入业务库。

原路径、SHA256与清理证据见 [清单](../../../docs/sdd/evidence/2026-10-21-safe-cleanup/manifest.json)。`sha256` 记录原工作副本字节，`git_sha256` 与 `git_blob` 绑定原仓库内容；跨平台检出只允许CRLF／LF换行差别，不改写样例数据。
