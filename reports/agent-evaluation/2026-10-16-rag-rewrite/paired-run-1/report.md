# Agent 0.9.0 RAG真实模型对照

## 设计

- 15题，每题A/B各运行一次，共30次；AB/BA交替，不选择性重跑或替换失败结果。
- 固定DeepSeek deepseek-flash、thinking disabled、配置修订3；本地BGE-M3、bge-reranker-v2-m3，候选30/证据5。
- A关闭新查询链路；旧检索函数正文与保存的0.8.1源码AST一致。B启用当前默认查询链路。其他Agent逻辑相同，属于查询链路对照，并非整个系统版本回滚。
- B默认中文/英文目标、首轮最多4路、补检最多2路一次、改写模型最多2次、每次5秒。未为本测试调长超时。
- 运行前固定15个输入、支持片段组和相关片段标签。当前公开库50个英文片段；只读真实向量库。
- 知识复核依据本库原文，没有独立访问来源网站核验。未覆盖多语言正文混合知识库和真实买家权限。

## 改写与补检表现

- **翻译及多查询确实执行。** B进行了19次改写模型调用，15题首轮各4路，另4题各补查2路，合计68次真实向量查询；A为15次。原问题保留、目标语言默认中英，阿拉伯文输入也成功完成问答。
- **没有观察到补检净收益。** 第5、6、7、14题触发并标记采用补检，四题首轮与最终片段ID顺序均相同，支持点新增为0。第5–7题缺口在知识库；第14题缺口发生在选证据阶段。retry_adopted只表示程序采用，不代表质量提升。
- **第14题已复现到具体排序。** 原中文查询的补充复算将74排第1（0.02946）；B的中英拼接锚点将65/68/74排为第1/2/3，分数0.99469/0.99124/0.98649。三者同属ISO文档，每来源最多2段的规则丢弃74，改为选入其他国家文化等片段。B补检后重现同一排序。
- **相同B候选池的英文单锚点诊断。** 只用已生成的英文问题重排，74回到第1（0.12666）并保留。该诊断只调用本地reranker，没有再调用DeepSeek生成答案，也没有替换原30次结果；只能证明本题拼接锚点存在影响，不能据此宣称所有问题改用英文都更好。详见case14-rank-diagnostic.json。
- **覆盖判定有盲点。** 74是适用于所有茶类的通用冲泡原则，不逐字包含green tea；当前同片段对象+主题匹配不能理解这种适用关系。第13题的专有产品名则不在有限实体词典中，虽然没有任何产品证据，B仍记录remaining_issues为空；最终由生成回答拒答。
- **指标边界。** 预标注相关片段集合并非穷尽，例如第9题62也直接涉及红茶工艺但未列入预注册集合；原指标不作事后改写，因此片段占比是预注册集合命中情况，不是严格Precision。支持点覆盖也不能衡量微生物等证据外补充或译名错误。
- **费用与时延。** 模型调用32→51（+59.4%），已返回Token总数89,029→111,024（+24.7%）。平均22.539→22.349秒，仅差0.190秒；受单次采样、答案长度和A第14题降级影响，没有稳定提速结论。

## 已知问题与后续顺序

1. 优先修复重排序查询：针对当前英文库采用单个语义完整的英文锚点，或分别对原问/翻译排序后融合；避免将两种语言直接拼接。用第14题固定候选验证，再扩展到独立问题。
2. 调整证据选择：保留直接回答问题的关键片段，允许必要时突破单来源软上限；来源多样性不应使核心冲泡说明被无关文化片段替换。
3. 补全覆盖评估：支持通用原则适用于茶类子集的关系，识别未知专有名词、配方等直接证据需求，避免仅命中国名便判断资料充分。
4. 将改写改为按需触发并限制无收益补检：本组原链路已有较高跨语言覆盖；对库内缺失的国家/主题提前指出缺口，减少重复模型与向量调用。
5. 补充阿联酋习俗的可核实资料，并在召回和生成阶段限制偏题贸易背景；统一black tea/红茶、dark tea/黑茶及资料发布年与统计年。
6. 修复后保留本次原始结果，原样复跑并增加难例、多次配对及混合语种知识库测试；当前结果不支持宣称新版整体优于单查询。

## 完整性与限制

- 生产源码哈希前后一致：True；公开知识快照前后一致：True。
- 业务表起始计数：`{"turns": 23, "conversations": 7, "spans": 221}`；结束计数：`{"turns": 23, "conversations": 7, "spans": 221}`。本执行器使用不提交业务会话的PreviewSession，遥测关闭；若其他页面同时使用系统，计数变化不能归因于本测试。
- 单次配对、小样本且部分题目互为翻译，不能推断总体准确率或统计显著性；网络和答案长度影响整轮耗时。
- Token仅汇总服务返回的usage；超时调用没有返回的用量不在统计中，不估算费用。
- 阿拉伯文输入测试不要求输出阿拉伯文；目标检索翻译仍为默认中英。
- 未修改线上参数或生产代码，保留全部成功、失败和降级记录。
